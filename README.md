# truck-logistics-calculator
Веб-приложение для дальнобойщиков и логистов: расчет маршрутов, расхода топлива, расходов на рейс и генерация путевых листов.
# 🚛 Дальнобой-Логист: Расчет рейсов и логистика

**«Дальнобой-Логист»** — это современное веб-приложение для водителей-дальнобойщиков, логистов и владельцев автопарков. Приложение помогает точно рассчитать экономику рейса, проложить оптимизированный маршрут и автоматически подготовить сопроводительную документацию.

---

## 🌟 Основные возможности

- 🗺️ **Интерактивные карты и маршрутизация:** Построение оптимального маршрута по точкам с использованием **Leaflet** и **OpenStreetMap**.
- ⛽ **Расчет расходов и топлива:** Учет расхода топлива, стоимости за литр, платных дорог, суточных и амортизации транспортного средства.
- 📊 **Финансовая аналитика:** Расчет чистой прибыли рейса, стоимости километра пути и рентабельности.
- 📄 **Генерация документов:** Автоматическое формирование путевых листов и отчетов по рейсу.
- 🤖 **AI-помощник:** Интеграция с **Google Gemini API** для умных подсказок по маршрутам и оптимизации расходов.

---

## 🛠️ Технологический стек

- **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons, Leaflet
- **Backend:** Node.js, Express
- **AI Integration:** Google GenAI SDK (Gemini)
- **Deployment & Tooling:** PostCSS, Autoprefixer
